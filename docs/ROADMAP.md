# Roadmap

## Phase 1: Foundation

- Initialize frontend and backend projects
- Configure environment variables
- Connect database
- Add linting and formatting
- Add base layout and routing

## Phase 2: Authentication

- Register
- Login
- Logout
- Current user endpoint
- JWT middleware
- Protected routes
- Role-based route guards

## Phase 3: Queue Core

- Services CRUD
- Counters CRUD
- Token generation
- Token status updates
- User dashboard
- Staff dashboard

## Phase 4: Real-Time Updates

- Socket.IO server setup
- Socket.IO client setup
- Queue rooms by service or counter
- Live token display
- Real-time dashboard updates

## Phase 5: Admin and Reports

- Admin dashboard
- Staff assignment
- Queue open/close controls
- Queue history
- Search and filters
- Average waiting-time statistics

## Phase 6: Polish and Deployment

- Loading states
- Empty states
- Error states
- Mobile and tablet responsive testing
- README setup instructions
- Seed demo users
- Deploy frontend, backend, and database
